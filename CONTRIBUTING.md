# Contributing to Orlando Devs Website

Thank you for your interest in contributing to the Orlando Devs website! We welcome all contributions, big or small, to help improve our community platform.

## How to Contribute

1. **Fork the Repository**
   - Click the "Fork" button at the top right of this repository page to create your own copy.

2. **Clone Your Fork**
   - Clone your forked repository to your local machine:

     ```sh
     git clone https://github.com/your-username/website.git
     ```

3. **Create a Branch**
   - Create a new branch for your feature or fix:

     ```sh
     git checkout -b my-feature-branch
     ```

4. **Make Your Changes**
   - Edit files, add features, or fix bugs as needed. Please follow the existing code style and structure.

5. **Test Your Changes**
   - Run the site locally with `npm run dev` and verify your changes work as expected.

6. **Commit and Push**
   - Commit your changes with a clear message:

     ```sh
     git add .
     git commit -m "Describe your change"
     git push origin my-feature-branch
     ```

7. **Open a Pull Request**
   - Go to your fork on GitHub and click "Compare & pull request". Fill out the PR template and submit.

8. **Review Process**
   - An admin will review your pull request. Please respond to any feedback or requested changes.
   - All GitHub actions must pass before merging.

## Code of Conduct

By participating, you agree to abide by our [Code of Conduct](./src/pages/codeofconduct.astro).

## Need Help?
