# Changelog

## [1.0.0] - 2025-06-29

### First Release

This is the initial release of the New Orlando Devs website (v3).

This site is **Built with Astro v5.0.4**

#### Features

- Modern, responsive design using Astro, React, and Tailwind CSS
- Home page with community hero section and featured image
- Dynamic group listing with logos, descriptions, and event links
- Event pages for each group, with upcoming and past event support
- Sponsors page with grid layout, hover effects, and sponsor details
- Board of Directors and Board of Advisors sections, sorted and data-driven
- About page with organization mission and team
- Code of Conduct page outlining community guidelines
- Navigation bar with dropdown for groups, Discord invite, and Code of Conduct link
- Mobile-friendly navigation and layout
- All group, sponsor, and board data managed via JSON for easy updates
- Discord replaces Slack for all community chat references
- Accessibility and UX improvements throughout
